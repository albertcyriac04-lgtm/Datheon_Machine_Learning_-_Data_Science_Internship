Model Inference Demonstrations

This app serves predictions from models trained in the accompanying Jupyter notebooks and saved as pickle files. Choose any task below to test with sample or custom values.

Task 1: Iris Flower Classification

Multi-class classification pipeline using StandardScaler and Logistic Regression. Model loaded from models/iris_model.pkl.

Click "Run Prediction" to view output.
Predicted Species

Task 2: California Housing Price Prediction

Continuous regression model predicting median house values based on census attributes. Model loaded from models/housing_model.pkl.

Click "Calculate Estimate" to predict price.
Estimated Median Value

Calculated using regularized regression coefficients with engineered features (rooms per household & bedrooms ratio).

Task 3: Telecom Customer Churn Prediction

Ensemble classification identifying customers likely to cancel subscription. Model loaded from models/churn_model.pkl.

Click "Evaluate Attrition Risk" to assess customer.
Assessment Outcome

Task 4: Customer Review Sentiment Classifier

TF-IDF vectorizer paired with Naive Bayes trained on customer reviews. Model loaded from models/sentiment_model.pkl.

Click "Classify Sentiment" to inspect polarity.
